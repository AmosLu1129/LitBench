# 欢迎页设计规格 ·《窗前晨光》

> 状态：2026-11-13 设计稿；**M6a / M6b / M6c 已交付**，剩余为美术精修与移动端。
> 代号：**M6 · 欢迎页**（独立支线，不阻塞 M5 写作侧）。
> 关联：`README.md`（定位：证据中间层）、`docs/15-知识库与Agent协作长线计划.md`（长线）、
> `docs/06-前端.md`（现有前端约定）、`docs/09-现状交接.md`（默认先读 §0.0）。
> 一句话：**一间只有桌案被照亮的书房，窗缓缓开了，晨光带着薄雾落在书卷上。**

---

## 0. 为什么是这个场景

产品的承诺是「每条断言都能回链到页 / bbox / 复核记录」，这句话抽象讲，讲不清。这个场景把它变成**一个物理动作**：

| 画面里的东西 | 对应的产品含义 |
| --- | --- |
| 窗外（桃枝、飞鸟、远山） | 文献的世界——广阔、未读、有待辨认 |
| 桌案与书卷 | 你的写作现场：正在被使用的那一页 |
| 油灯（开场唯一光源） | 旧式阅读：只有自己的一盏灯，局部、私密、无法核验 |
| 晨光（开窗后涌入） | 证据被照亮并**送到**桌面上；这是全片的动词 |
| 书页上的朱批与引线 | 引用链：一句话连到它的出处 |
| 朱印「可核」 | 人工复核 / 采纳——落定 |
| 冰裂纹窗影 | 唯一的装饰纹样；光被切成碎纹投在纸上 |

于是上一轮定下的题目在这里变成**字面意思**：

> **循光至页** —— 光从窗外来，落在书页上，你循着它找到那一页。

副标题沿用：**每一句话，都能回到它出生的那一页。**

### 为什么不是抽象光效

抽象的光丝、星图、粒子，谁都能做，也就说明不了"我们是谁"。而这个场景里有两样东西是别人搬不走的：**书页上真的有一条引线**，**光真的落在一个框里**。产品机制不需要旁白解释，只需要被看见。

## 1. 非目标

- **不做全景房间**，不做可自由漫游的 3D 空间。镜头永远在桌面上方 35cm 左右，不穿窗、不出室。
- **不做 3D 中文文字**。标题一律 DOM；书页文字用纹理贴图。
- **不做实时数据大屏**。页脚数字默认静态（见 §12）。
- **默认不播放声音**。音效作为可选项（见 §14 未决项）。
- **不动主应用的视觉 token**。欢迎页用本文 §4 的独立色板，只共用字体栈。
- **不追求移动端 1:1 还原**。竖屏走静态帧 + 轻视差（见 §11）。
- **不在这一阶段改任何后端接口**（唯一例外见 §12 的待定项）。

## 2. 观众、时长与节奏

| 项 | 规格 |
| --- | --- |
| 首访 | 自动播放 **34 秒**一镜到底，可跳过 |
| 3 秒原则 | 标题在 DOM 里第一帧就渲染（不等 3D），墨渗显影 |
| 回访 | 直接呈现「开窗后」的定格（有光状态），角落留「重看开窗」 |
| 循环 | 34s 之后进入 idle：灯焰呼吸、尘埃、光斑 40s 周期漂移、鸟低频掠过 |
| 设备目标 | 桌面 Chrome/Edge 集显 **60fps @1440p**；移动端 30fps 或静态 |

## 3. 场景与构图

### 3.1 空间

只拍局部。三层景深，缺一不可：

- **前景**（虚化）：左下方油灯，右下方笔架与镇纸的边缘。
- **中景**（焦点）：半展的手卷，占据画面下三分之一。
- **背景**（次焦外）：窗与窗外的桃枝、鸟、远山。

画面**上三分之二留给光与留白**，桌面只在下三分之一。宋画的「平远」靠这个比例，不靠画山。

### 3.2 窗

- 四扇隔扇窗，中间两扇**向外对开 55°**。
- 窗棂为**冰裂纹**：不是装饰选择，而是因为它是全片唯一的光影雕刻工具。
- **不出现人手**。由风推：先试探性地推开约 10°，停 1 秒，再缓缓全开；木轴留极轻微的卡顿（老木轴）。
- 关窗状态靠**一线窗缝冷光**勾出窗棂轮廓——这是开场的唯一"远景信息"。

### 3.3 桌

- 明式平头案，深栗木，木纹细、微反光（roughness ≈ 0.35），油灯在桌面形成一小块暖色高光池。
- 桌角一枚**浅茶痕**（杯圈水渍）。这是"有人在这里读过书"的唯一证据，成本几乎为零。
- 全场景不出现任何一件多余的摆件。

### 3.4 书卷

- 半展手卷：绫绢包首、朱漆轴头、宣纸（近景可见**帘纹**）。
- 页面上有三样东西：墨字、**朱批**（红笔批注）、**一条连向插图的细引线**。
- 插图不做虚构山水：**用库里真实的图表**，去色、加纸纹、做单色石印处理。《天工开物》那种风格。这样"这本书真的就是这个库"。

### 3.5 窗外

- **桃枝**：一枝斜入画面右侧（折枝式构图）。
- **鸟**：3 只，全部剪影，小、快、远。开窗瞬间，枝上那只**先惊飞**——它是全片的节拍器。
- **远山**：3 层雾青剪影平面，做视差，不是 3D 山。
- **天空**：从靛青到浅金，薄云如纱。

### 3.6 相机

| 项 | 规格 |
| --- | --- |
| 焦段 | 50mm（等效），全片不变 |
| 光圈 | f/2 虚拟景深（浅） |
| 机位 | 桌面高约 35cm，略低于书页平面，微微仰视 |
| 运动 | 总计不超过 3 个动作：微推 5cm、推成特写、抬起 20° |
| 禁令 | 不环绕、不甩镜、不穿窗 |

## 4. 色彩与光

### 4.1 六色

| 色 | 色值 | 占比 | 用在哪 |
| --- | --- | --- | --- |
| 墨 | `#1B1713`（最暗 `#14110F`） | 45% | 房间暗部、窗棂、字迹 |
| 木 | `#4C382A` | 20% | 桌案、窗框、轴头 |
| 纸 | `#EFE3C9` | 18% | 书卷、信笺、题字底 |
| 光 | `#F0C185`（最亮 `#FFF6E6`） | 12% | 晨光、灯焰、尘埃高光 |
| 雾青 | `#9AA9A4` | 3% | 远山、窗缝冷光、窗外空气 |
| 朱砂 | `#A63B2B` | 2% | 朱批、引线、印章 |

约束：**色相不超过 6 个；朱砂不超过 2%；不用纯黑纯白。** 红一多就不像印章，像主题色。

### 4.2 光比与色温

| 时刻 | 冷暖比 | 色温 | 曝光 |
| --- | --- | --- | --- |
| 开场（关窗） | 9 : 1（冷为主） | 窗缝 8000K / 油灯 1900K | −2 档 |

**颜色本身在讲故事**：从冷暗走向暖金，不用一句文案解释。

## 6. 光源

| 光源 | 类型 | 色温 | 强度 | 阴影 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 油灯 | 点光源 | 1900K | 局部主光 | 无（或 512） | 缓慢闪烁 ±5%，低频噪声，不规律 |

| 天光 | 半球光 | 6000K | 0.3 | 无 | 补暗部，防止全黑 |
| 环境 | 自建双色渐变 env（PMREM） | — | — | — | 不用 HDRI，省体积 |

## 7. 时间轴（34 秒一镜到底）

| 时间 | 画面 | 光 | 相机 | 技术事件 |
| --- | --- | --- | --- | --- |
| 0–3s | 暗室静帧：桌案前缘、油灯、半展书卷；窗缝一线冷光勾出窗棂 | 油灯 1900K 呼吸 ±5%；冷光 8000K | 静止，微推 5cm | 标题已在 DOM 里墨渗显影 |
| 3–7s | 风试探着推窗 10°，停 1s，再缓缓开到 55°；木轴轻卡顿 | 缝隙变成光带 | 微推 | 窗扇枢轴动画（easeInOutCubic，约 3s） |
| 7–12s | 光带扫过桌面，冰裂纹影子从书卷左下斜移到右上并被拉长；尘埃首次现身 | 色温 3200K，曝光 5 秒爬升 2 档 | 微推至中景 | 方向光 + 阴影贴图逐帧更新 |
| 12–18s | 推成 50mm 特写：光扫过一行字 → 停在朱批引线上 → 引线被"点着"透亮 → 顺线移到插图 → **插图一角被光框住 0.8s** | 局部高光沿引线移动 | 推成特写 | 全片唯一机制镜头，见 §7.1 |
| 18–24s | 抬起 20°，窗外入画：桃枝斜入右侧、两只鸟从左掠过、远山三层雾青；枝上那只先惊飞 | 逆光，鸟成剪影 | 抬起 | 惊飞与开窗同时触发 |
| 24–30s | 回落书页。晨光扫过处，标题墨迹一点点浮出（不是淡入，是被光照显影）；落款稍后；朱印最后压下 | 光斑边缘掠过字面 | 回落 | DOM mask 沿光斑方向擦除 |
| 30–34s | idle：灯焰呼吸、尘埃漂浮、光斑 40s 周期漂移、鸟低频掠过 | 晨光缓慢升温 | 静止 + 鼠标视差 | 进入循环 |
| 34s+ | 滚动：光带扩张 → 过曝成白场 → 转入工作台 | 曝光 +2 档 | — | 换 chunk |

### 7.1 机制镜头（12–18s）

这一下是全片的命门，也是**唯一出现产品机制**的地方：

1. 光落在书页某一行字上（用真实 block 坐标）；
2. 顺着**朱批引线**滑到旁侧插图；
3. 在插图的一个矩形区域**停住并框住** 0.8 秒——这就是 bbox 的视觉化。

做不准则全片只剩气氛，宁可前面 20 秒都安静，这一下也必须准。

## 8. 交互与转场

| 交互 | 行为 |
| --- | --- |
| 鼠标移动 | 相机 ±1.5° 视差，高光随之偏移（像头微动） |
| 滚轮 / 触摸下滑 | 光带扩张 → 过曝白场 → 进入工作台 |
| 悬停朱批 | tooltip：`第 12 页 · Fig.4 · 置信 0.96`（真实数据，见 §12） |
| 点击「跳过」 | 直接跳到开窗后的定格 |
| 点击「重看开窗」 | 从 3s 处重播，不重新加载 |
| 键盘 | `Enter` 进入工作台；`Esc` 跳过动画 |
| `prefers-reduced-motion` | 不播放动画，直接给开窗后静态帧 |

**转场**：过曝到白 → 白场淡出 → 工作台淡入。比任何遮罩、任何缩放都干净，也最便宜。

## 9. 排版与文案

### 9.1 版式

- **右侧竖排题字**：`循光至页`。思源宋体 600，超大字号，字距 −0.02em。
- **竖排落款**（题字左下，小字）：`LitBench · 文献证据工作台`。
- **朱印**：落款下方偏右，字 `可核`（备选 `已核`）。**必须手绘成 SVG 篆刻**——篆书字体几乎都会俗、会假。
- **左侧横排副标**：`每一句话，都能回到它出生的那一页。` 思源宋体 300，小字号，字距 +0.2em（与主标形成疏密对照）。
- **CTA**：`展卷`。hover 时墨晕从字心向外扩散。
- **页脚**：真实数据一行（可选，见 §12）+ 极小的 `Lit — 点亮` 彩蛋。

### 9.2 字号层级

| 层级 | 字号 | 字重 | 字距 |
| --- | --- | --- | --- |
| 竖排题字 | `clamp(56px, 7vw, 112px)` | 600 | −0.02em |
| 副标 | `clamp(15px, 1.4vw, 19px)` | 300 | +0.2em |
| 落款 | `clamp(11px, 0.9vw, 13px)` | 400 | +0.15em |
| CTA | 15px | 500 | +0.35em |
| 页脚 | 11px | 400 | +0.1em |

字体栈沿用现有 `--font-serif`（Inter → Source Han Serif SC → Noto Serif CJK SC）。**中文只做子集化**，只打包用到的字。

### 9.3 响应式

- 桌面（≥1024px）：竖排题字在右，副标在左，如宋版书题名。
- 平板：竖排保留，缩字号，副标下移。
- 竖屏手机：**题字改横排居中**，朱印落右下，3D 走静态帧（见 §11）。

### 9.4 无障碍

- 标题、副标、CTA 全部真实 DOM，可选中、可搜索、可读屏。
- canvas `aria-hidden="true"`，不抢焦点。
- 文字对比度 ≥ 4.5:1（在暗底上，纸色字要避免落在暗角）。
- 提供「跳过动画」，且不自动播放声音。
- 不做闪烁：灯焰闪烁幅度 ≤5%，频率远离 3Hz。

## 10. 技术架构

### 10.1 依赖决策

**用原生 three.js，不引入 R3F / drei / GSAP。**

理由：

- 只有一个 60fps 场景，R3F 的抽象收益小，包体约多 50KB；
- 时间轴是线性的、可枚举的，写一张关键帧表 + 一个 clock 比引入 tween 库更可控；
- 缓动函数十几行就够（`easeInOutCubic`、`easeOutQuad`）。

依赖清单：`three`（锁 minor 版本）；构建与类型走现有 Vite 5 + TS strict。

### 10.2 目录

```
web/src/welcome/
  Welcome.tsx          # 入口组件：DOM 排版 + canvas 挂载 + 生命周期
  scene/
    setup.ts           # renderer / scene / camera / composer
    stage.ts           # 桌、窗、书卷的装配
    window.ts          # 窗扇开合动画与枢轴
    lighting.ts        # 4 盏灯 + 环境 + 闪烁
    atmosphere.ts      # 雾平面、体积光、尘埃
    outside.ts         # 桃枝、鸟、远山、天空
    timeline.ts        # 关键帧表 + 状态机
  materials/           # 纸/木/瓷/铜 材质工厂
  shaders/             # 纸透光、雾面、光柱、尘埃、花瓣
  ui/                  # 竖排题字、朱印、CTA、跳过、光标
  assets.ts            # GLTF/贴图加载与进度
```

### 10.3 入口与分包

`web/src/main.tsx` 做**入口分流**（不改 `App.tsx`）：

```ts
const Welcome = lazy(() => import('./welcome/Welcome'))
const App = lazy(() => import('./App'))
const seen = localStorage.getItem('litbench.welcome.seen') === '1'
// 首访 → Welcome；回访或 ?welcome=0 → App
```

好处：three 全部落在 welcome chunk，**工作台首屏体积零增加**；「进入工作台」= 写 localStorage + 过曝 → `location.replace('/')`，此时还没有任何用户状态，重载无损失。

### 10.4 渲染管线

```
WebGLRenderer（ACESFilmicToneMapping, sRGB, DPR≤1.5）
  → EffectComposer
      → RenderPass
      → UnrealBloomPass（低强度、高阈值，只让灯焰与光带溢出）
      → ShaderPass（vignette + 极轻 film grain，纸感）
      → SMAA
```

### 10.5 关键实现手法

| 效果 | 手法 | 为什么 |
| --- | --- | --- |
| 纸的透光 | 双面平面 + fresnel 边缘 + 背光 tint | 不用 `transmission`（集显掉帧） |
| 薄雾与光束 | 屏幕空间径向模糊 + 噪声雾面 billboard | 假体积光，性价比最高 |
| 尘埃 | Points 约 1500，只在光柱内可见 | 一次 draw call |
| 灯焰 | 平面 + 顶点噪声 + 一盏点光闪烁 | 不用粒子 |
| 飞鸟 | 剪影平面 + 双帧扇翅 | 远、小、快，不必做羽毛 |
| 窗棂影 | 方向光 + 2048 PCFSoft | 场景灵魂，不能省 |
| 书页文字 | 4K 纹理图集（真实语料渲染） | 不做 3D 中文 |
| 标题显影 | DOM：`mask-image` 沿光斑方向擦除 | 全站最便宜的一笔华丽 |
| 过曝转场 | 曝光曲线冲到 +2 档再切白 | 换个页面而已，不必做遮罩 |

## 14. 风险与未决

### 已识别的风险

1. **80% 的工作量在资产，不在 shader。** 15–25 个 mesh 加 4 张 4K 贴图，风格统一比技术难。
2. **窗棂影子**是性能与画质的交叉点。中低端 GPU 要准备烘焙方案（贴图随角度位移）。
3. **书页贴图清晰度**：50mm 特写会放大纸面，4K 图集可能仍不够，需 M6b 前实测。
4. **"像游戏 demo" 的风险**：只拍局部 + 浅景深 + 大暗部来规避；一旦给全景就完了。
5. **中文竖排**：`writing-mode: vertical-rl` 在窄屏与标点挤压上要单独调，移动端直接改横排。
6. **字体子集**：只打包用到的汉字，否则宋体会拖慢首屏。

## 16. M6b 质感重做（2026-11-13 第二轮）

用户看完 M6a 的评价是「简陋、火苗不动、窗外是 2D、没有太阳光、没有景深」。这一轮把渲染管线整个换掉。

### 16.1 换掉了什么

- **后处理链**：`EffectComposer`（HalfFloat + 4× MSAA）→ Render → 屏幕空间光轴（44 次亮度加权径向采样，
  太阳屏幕位置来自真实太阳球）→ Bokeh 景深（跟焦曲线：起幅对窗 2.75m → 书卷 1.9 → 纸面 0.95 →
  窗外 2.3）→ UnrealBloom（0.22 / 0.6 / 1.0）→ 胶片（暗角 + 颗粒 + 极轻色差）→ `OutputPass`。
- **真太阳**：窗外有太阳球 + 大光晕，随开窗一起升起；平行光角度改到 42°，光带真正落在书卷上
  （M6a 落在桌沿外），纸面上能看到冰裂纹棂条的投影。
- **三维窗外**：4 层带高度噪声的山脊（顶点色做空气透视，镜头移动有真视差）、6 棵低模树、
  3 只真三维的鸟（锥体身体 + 两片可扇动的翅）、3 层雾带、天空与太阳。
- **桃枝**：CatmullRom 曲线 + 分段 `TubeGeometry` 做渐细枝条（3 主枝 + 3 细枝），
  150 朵花簇 `InstancedMesh`，34 片飘落花瓣（逐帧矩阵）。
- **火苗**：两层 billboard + 自定义噪声着色器（泪滴外形、边缘翻卷、亮度抖动），灯芯 + 灯身改用
  `LatheGeometry` + 铜材质 + 环境反射；点光按同一节拍闪烁。
- **青烟**：噪声 + 摆动着色器，透明度压到 0.02，只在灯上方一缕。
- **材质**：程序化 bump（纸纤维 / 木纹 / 灰泥）、金属 metalness/roughness、瓷与漆用 `MeshPhysicalMaterial`
  的 clearcoat、墨面近镜反射；环境贴图是自制的等距柱状图（暗室 + 亮窗 + 暖灯）经 PMREM 生成。
- **接触阴影**：书卷 / 油灯 / 茶盏 / 书堆 / 砚各一片径向阴影贴片，让它们真的坐在桌面上。
- **道具**：茶盏（旋转体）+ 茶汤、带墨池的砚、笔架与毛笔、铜镇纸、三本叠书、窗台薄尘。

### 17.4 投影频闪修复（2026-11-13）

- 现象：油灯光与窗外日光投在桌面 / 纸面上的影子会"频闪"。
- 根因两条：
  1. 灯焰用 `sin(t·7.3)` + `sin(t·13.1)` 直接调制点光强度，幅度约 **±12.5%**，
     相当于 **1.2–2.1Hz** 的亮度方波——正好落在人眼敏感区，影子的对比度跟着一起跳；
  2. `shadowMap.autoUpdate` 保持默认 true，每帧都把方向光与点光的阴影贴图重算一遍，
     PCFSoft 的边缘在高对比投影上会随帧轻微抖动。
- 修法：
  1. 灯焰改成低频轻呼吸：`1 + sin(t·3.1)·0.018 + sin(t·5.3)·0.012`（约 ±3%，0.5–0.85Hz）；
  2. 静态场景冻结阴影：`shadowMap.autoUpdate = false`，只在窗扇角度真的变化时
     （开窗的 3–7.5s）置 `needsUpdate`，其余时间不重算；
  3. 油灯阴影 512→1024，`normalBias 0.02`，减少点光源阴影的自遮挡噪点。
- 验收：t=10 / 18 冻结帧里窗棂影子仍正确投在桌面与纸面；实播连拍 0.7s 的桌面区域
  平均亮度差 **−1.03/255（约 1.2%）**，残余差异来自相机推轨与浮尘，不是光照跳变。
