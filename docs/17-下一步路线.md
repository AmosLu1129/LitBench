     字段加权、子串加分保留旧 LIKE 的片段命中），不依赖 jieba/FTS 扩展，SQLite 与
     Postgres 行为一致；`search_figures` 语义路径改为 BM25（`engine=bm25`、
     `degraded=false`），`GET /api/papers?q=` 同步升级（标题/摘要/作者/citekey/标签，

## 8.1 工作组模型（2026-11-15 已拍板；前后端均已实现）

数据模型（迁移 0014）：

| 表/字段 | 说明 |
| --- | --- |
| `workgroup` | 工作组：id / name / description / created_by / created_at |
| `workgroup_member` | 成员：workgroup_id + user_id（联合主键）/ role=owner\|member / joined_at |
| `paper.owner_user_id` | 私有库归属；上传时写当前用户；旧数据为 NULL（暂视为 legacy，可见） |
| `paper_share` | 共享：paper_id + workgroup_id（联合主键）/ shared_by / shared_at |

| `claim.owner_user_id` | 写作卡片归个人（共享留给后续） |
| `user_paper_state`（可选） | 同一篇被共享的文献，笔记/收藏/阅读状态按用户隔离；v1 先做 owner 私有，非 owner 只读 |

访问规则：

1. 私有库列表 = `owner_user_id = 我` 的文献（+ legacy NULL）；
2. 团队库列表 = 我所在工作组里 `paper_share` 命中的文献；
3. 文献详情/图/表/摘要：按「能看见这篇 paper」再放行；
4. 共享/取消共享：文献 owner 或管理员；工作组 owner 管理成员；
5. 管理员可看全部，但界面默认只看自己的库，避免误操作。

### 11.3 学位论文 LaTeX 包（用户已拍板只做 LaTeX；2026-11-15 ✅ 已交付）

目标：把库里的 claim 卡片 + 文献元数据装进一份**学位论文骨架**（章节骨架、引用、
GB/T 参考文献），不做全文排版器、不做 Word、不做学校定制模板。

#### 11.3.1 数据模型（迁移 0015）

- `paper.entry_type`（String(16)，默认 `journal`）：`journal|conference|preprint|thesis|book|report|other`；
  Zotero 的 `itemType` 已有（`ZItem.item_type`），导入时映射并落库
  （`thesis→thesis`、`journalArticle→journal`、`conferencePaper→conference`、`preprint→preprint`…）；
  旧数据一律 `journal`，不改历史格式。
- `paper.thesis_school` / `degree` / `place`（nullable）：Zotero `university` / `thesisType` / `place`；
  手工补全走现有 `PATCH /api/papers/{id}`（`PaperPatchIn` 加字段），`PaperOut` 一并返回。

  `作者. 题名[D]. 出版地: 学校, 年份.`（无 place 省略「出版地:」；缺学校/年份进 warnings，不瞎编）；

#### 11.3.3 学位论文骨架导出（后端）
